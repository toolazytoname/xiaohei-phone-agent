## 证据规则

- 源码修改、单元测试和静态扫描只证明实现，不能替代环境或用户可见的验收。
- 夹具、mock、同机 profile-disabled 运行必须如实标注，不能满足独立账号/设备门禁。
- 同一失败指纹只记录一次；先改变条件或修复再复测。没有新条件时，重复截图、声学提示或付费模型调用不是新证据。
- debug 或测试签名 APK 只能作为内部验收工件，不能作为公开 Release 宣传。
