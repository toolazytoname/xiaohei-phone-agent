# 小黑数据流与保留规则

[English](privacy-data-flow.md) · [隐私说明](privacy.zh-CN.md) · [威胁模型](threat-model.zh-CN.md)

状态：截至 2026-08-11 的 `SEC-002` 代码与契约盘点。它不是对中转站、Android OEM 服务或第三方接收端已经通过独立隐私审计的声明。

## 全类别通用规则

- 模型、Phone Agent、OpenCode 或 root capability 都不会天然取得读取设备数据的权利；必须分别通过类型化策略、确认和工具边界。当前 Conversation 路径没有动作权限。
- 原始音频、屏幕像素、无障碍树、Prompt、通知正文和 Token 不得进入脱敏 Agent JSONL、诊断导出、公开契约夹具、Git 或公开文档。
- App 私有状态不等于公开导出。唯一的轨迹导出必须由用户点击、明确标注为脱敏，并交给 Android 选择器；选择接收方是用户独立作出的披露决定。
- 按正常 Android 包数据语义卸载会移除 App 私有文件和偏好；不会删除 Android、所选 TTS 引擎、中转站或用户选择的分享接收方自行保留的内容。

## 边界检查与待补证据

仓库验证器会检查此双语表是否列出六个必需类别与 release 可见的禁止项。单元与静态检查覆盖有界会话、隐私拒绝、轨迹排除、无 Token 备份和无原始截图持久化；它们不会检查远端端点、Android 系统服务、其他 App、崩溃转储、OEM 日志或用户选择的导出接收方。

公开发布前，应在独立设备和真实配置中转上重新做数据流演练，只采集脱敏证据：权限/撤权转变、停止后的 recorder 数、App 私有文件清单、Token 清除/重启、轨迹清除/导出，以及通知/位置/私人媒体拒绝。原始消息、音频、截图、endpoint、Token 或设备标识不得进入 Git。
