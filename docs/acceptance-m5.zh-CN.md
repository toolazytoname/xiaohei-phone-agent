# M5 可见 Phone Agent 验收记录 — 基础纵切

日期：2026-08-09  
设备：OnePlus 8T / Android 14

## 真机证据

- 本轮主动启用可选无障碍服务，状态为 `CONNECTED`。服务生成有界 `snapshot.v1` 语义树：最多 160 节点、深度 14；密码节点固定替换为 `[REDACTED]`。当前不采集截图。
- 一个可见单步任务打开 Android 设置，按精确文本找到“网络和互联网”，点击可点击节点或其祖先，然后重新观察新快照。轨迹为 1 步、`ok=true`、before 版本 1、after 版本 2、包名 `com.android.settings`。
- 第一次执行暴露了策略粒度过粗的问题：设置首页的“密码与账号”入口导致整页被拒绝；产品在点击前安全停止。修正为区分“敏感目标/正在输入凭据”和普通索引项后，合法任务通过。
- 目标“输入验证码”在动作前被拒绝。不存在目标只允许一次恢复；恢复等待期间使用全局停止，得到 `task=stopped`，没有点击。
- 通过 `adb reverse` 调用本机 OpenAI-compatible mock。模型只返回一个 JSON 提议，界面完整展示 App、精确标签和说明；确认前没有动作。用户确认后，本地策略层只执行一次点击并重新观察成功。
- 共两次 mock 请求，没有调用外部模型或用户中转站 Token。验收后已删除 reverse、mock 配置、Accessibility 授权和通知监听测试授权；OnePlus DSP 保持 `DETACHED`。
- 最新候选完成设置“网络和互联网→互联网”真实两步任务，每步重新观察，得到 snapshot `1→2`、`3→4` 两条 success，最终进入 Settings `SubSettings`。
- 新增 256 KiB 有界脱敏 `agent-trace.v1.jsonl`；不保存语义树、截图、Prompt 或 Token。两条 success 与一条 deny 均通过 JSON 解析，敏感目标变为 `[REDACTED_POLICY_TARGET]`。验收后清空轨迹并再次撤销 Accessibility。
- Agent 执行现绑定预期包名：无障碍事件和根快照必须匹配该包。真机计算器跨 App 任务对 `com.android.calculator2` 中“1”精确点击一次并生成 success 轨迹；刻意抢切到设置页得到 0 点击，随后通过关闭服务停止。
- 收紧本地策略：即便某 App 已在允许列表，通用“允许 / 确认 / 下一步 / 继续 / 同意”等审批控件也不会被 Agent 自动点击；权限、账户/登录等可见页面一律升级为“需要确认”，支付、转账、卡号、验证码和密码表面继续默认拒绝。新增单元用例覆盖通讯录通知权限、通用下一步和付款金额场景。
- 安全入口矩阵验证发现 OnePlus 上 Aperture 的“相册”会交给 Termux 文件接收页。产品不再把它展示为稳定安全入口；执行器在每一步重新观察后也新增“目标包变化”门禁，若点击把焦点交给其他包，会记录 `package_changed` 并立即停止，绝不作为成功后继续执行。
- 计算器验证还发现同一文本可同时出现在公式输出和数字按钮中。节点查找现在优先选择具有可点击祖先的精确标签，避免被只读输出文本遮蔽；公式已含“1”时的真机复测再次通过。验收辅助脚本未能稳定处理 Android 下拉弹窗/无障碍状态，未纳入交付物；后续矩阵改用可见的人工语义选择或正式 UI 自动化框架。
- 包允许列表改为精确包名，不再接受前缀继承：未审核的 `com.google.android.*` 或 `org.lineageos.*` 包不能仅因厂商命名空间相同而获得访问权。每个支持包均逐项列出，仍受标签、页面、动作后包名、超时和全局停止检查约束。
- 当语义恢复无法找到低风险目标时，现有经用户同意的视觉恢复。它只在安全、包绑定的任务仍在等待时，通过可见 Agent 通知进入；Android 13+ 的通知权限在 Agent 页面中明确显示/请求。服务只截取一次内存图像，立即停止任务，随后可见 Agent 页面要求用户人工查看并重新给出精确低风险标签。它绝不上传图片、写入磁盘、写入 `agent-trace.v1`，也绝不据图自动点击。
- 在独立 Android 14 AOSP ARM64 模拟器上，DocumentsUI 的不存在标签进入一次恢复交接。验收 harness 调用了与通知按钮相同的受保护 service intent：截图成功、任何动作前任务停止、Agent 页面显示临时本机预览说明。App 私有目录仅存在原有 JSONL 轨迹，未发现图片文件或截图轨迹内容。真实通知点击仍是正常用户交互，绝不是自动动作。

## 本地强制边界

最多 8 步、总计 60 秒、一次恢复、重复动作保护、包允许列表、敏感页面拒绝和全局停止均在本地强制。模型不能直接调用 Accessibility。发送、删除、安装、授权和拨号属于单独确认等级；支付、银行、凭据、密码和验证码页面默认拒绝。

## 尚未满足的 M5 出口门禁

本纵切证明了“规划→预览→策略→多步语义动作→逐步重新观察→脱敏轨迹导出”和经同意的本机视觉恢复架构，但尚未完成整个 M5。仍需 10–15 个 App 任务矩阵和真实多步恢复。验收结束服务已关闭，必须由用户再次主动授权。
