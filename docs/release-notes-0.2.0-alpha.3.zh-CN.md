# 小黑 0.2.0-alpha.3 — 发布候选

[English](release-notes-0.2.0-alpha.3.md) · [发布范围](release-scope-0.2.0-alpha.3.zh-CN.md)

本候选把内部纵切收敛为边界清楚的通用包，并继续把模型和设备增强拆成独立工件。

## 主要变化

- 完成 M2 短命令契约：真实来电打断活跃听取后立即释放麦克风并回到 `ARMED`。
- 在独立 AOSP Messaging 完成 M4 通知/确认式草稿契约。确认只打开目标 App；小黑不填入也不发送消息。
- 完成 M5 可见 Phone Agent：十个不同 App 语义矩阵 10/10；用户主动触发的单次截图恢复只在内存展示，不上传、不落盘。
- 增加独立实测的 Android 14 ARM64 通用 profile：如实显示无 DSP、CPU KWS 可见启停、干净卸载、录音残留为 0。
- 增加可复现发布溯源打包和 KWS 语料工具。80 例合成诊断拒绝全部 40 条负样本，并命中两个可懂标准普通话 TTS 对照的全部变体；该结果明确不能代替真人准确率验收。
- 默认包版本升级为 `versionCode=4`、`versionName=0.2.0-alpha.3`。

## 分发边界

计划公开的通用候选包不内嵌 ASR/KWS 模型权重。私有组合模型包与 OnePlus DSP 增强均不是公开 Release 工件。“小黑小黑”仍是实验性、主动开启的前台 CPU 兜底，不宣称自定义 DSP 关键词。

## 剩余门禁

尚未上传公开 APK。[精确候选 ClamAV 扫描](malware-scan-0.2.0-alpha.3.zh-CN.md)、发布溯源和加密恢复解密演练现已通过；仍需物理待机/功耗、把恢复包移到独立控制的离线介质，以及最终公开上传批准。内嵌模型分发还受明确权利审核阻断。
