# M7 自定义唤醒词验收记录 — 部分完成

日期：2026-08-09  
设备：OnePlus 8T（`KB2000`），Android 14 / LineageOS 21  
候选版本：`0.2.0-alpha.2`（`versionCode=3`），debug 签名

## 真机已证明

- 官方 sherpa-onnx 1.13.4 中文 KWS 包已用 SHA-256 `1ee827227c1369b55e0aa5e35de93981ddcaa153238bfa21063260413278f07f` 固定；仓库不提交上游二进制。
- 一份 sherpa runtime 同时承载离线 ASR 与 KWS；构建删除未使用的重复 KWS checkpoint，产物约 64 MB。
- 唯一关键词为 `x iǎo h ēi x iǎo h ēi @小黑小黑`。两次独立普通话声学试验均在第一次呼叫得到 `keyword=小黑小黑`。
- KWS 先释放录音，再由可见 Assistant 会话取得麦克风；离线 ASR 结束后，CPU KWS 自动恢复为 `LISTENING`。
- 第二次试验进入命令路由，但 ASR 没有产出预期白名单命令，因此返回“未匹配命令”且没有动作。这是安全拒绝，不能记作语音到动作通过。
- alpha.2 后续按事件同步的试验完成完整声学链：12:12:36.973 得到 `keyword=小黑小黑`，12:12:38.481 离线 ASR 报 `speech_ready`，随后播放“打开相册”，12:12:42.311 得到 `OPEN_GALLERY ok=true`，系统 Photo Picker 前台显示，CPU KWS 自动恢复 `LISTENING`。
- 独立停止按钮把状态改为 `OFF`、销毁前台服务并释放活跃录音；DSP 始终为 `DETACHED`，CPU KWS 没有改变 DSP 状态。
- 监听时单点快照：总 PSS 约 149 MB、总 RSS 约 284 MB、thermal status 0。该数据不是续航结论。
- 小规模确定性声学基线播放 10 条中文相近负样本（小白、小爱、原厂小布、小米、颠倒/不完整小黑及普通命令），0/10 误唤醒；“小黑小黑”按语速 120/135/150/165/180 播放，5/5 命中，每次会话均恢复 `LISTENING`。该结果来自安静环境下同一个 Mac 合成声音，不是量产准确率语料。

## 独立通用 profile 与合成探针

- 干净 Android 14 AOSP ARM64 虚拟设备独立安装了 SHA-256 为 `70e23a097c2c82ba06d7c989a274b20be3f1da5f2874724e6c6f1647d99d1008` 的组合候选包。它如实显示没有 DSP profile，CPU KWS 默认关闭，只能经可见操作启动；启动后显示 `LISTENING` 和私密前台通知，停止后无活跃服务和录音客户端。
- 卸载后没有小黑包、App 进程、活跃服务、通知读取授权、无障碍授权或录音客户端。精确 profile 与宣发边界记录在 [`device-profiles/generic-android-api34-arm64`](../device-profiles/generic-android-api34-arm64/README.zh-CN.md)。
- 固定参数的离线评测器运行了 80 个一次性 macOS 合成用例：10 个系统音色的“小黑小黑”分别做干净、低音量、10 dB 噪声、合成混响，共 40 条正样本；另有 40 条相近词/普通命令负样本。40 条负样本全部拒绝；标准普通话音色 `Tingting`（大陆）与 `Meijia`（台湾）的 8 个变体全部命中，8 个 macOS 新奇音色均未命中。
- 另用固定的通用中文 ASR 模型复核：两个标准普通话音色都转写为“小黑小黑”，8 个新奇音色则全部返回空结果。因此，这些新奇音色不能证明输入是可懂的正样本，也不能计为 KWS 假拒绝。该语料只是确定性流水线诊断，不是音色鲁棒性或准确率验收；音频不提交，也不代表真人或物理距离。
- 对外承诺已主动收窄：“小黑小黑”只是实验性、主动开启的前台 CPU 兜底；OnePlus DSP profile 仍使用已验证的原厂词，不宣称已经支持自定义 DSP 唤醒词。

## 产品边界与未完成门禁

CPU KWS 必须主动开启，有前台通知和麦克风指示，功耗较高且默认关闭。它是通用兜底，不等于低功耗 DSP。第二独立通用 profile 和收窄公开承诺已有证据；M7 仍需真人多人/噪声/距离准确率与拔线功耗测试，这份合成探针本身不能让准确率晋级。
