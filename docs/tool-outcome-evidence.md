# Tool outcome evidence

`ToolOutcomeEvidenceGate` makes a successful adapter response insufficient by itself. A tool result is verified only when a newer minimal observation has the expected foreground package. Adapter failure, a stale observation, a mismatched package, or a second verification attempt fails closed.

The gate contains only package metadata and snapshot sequence; it has no screen text, tree, image, network, tool, or rollback execution capability. It is not yet wired to a real adapter/observer pair, so TOOL-012 remains `VERIFY` pending device evidence and a reviewed reversible-adapter catalog.
