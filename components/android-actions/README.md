# Android Actions

Contains observable, least-privilege actions implemented through Android intents, notification access, accessibility, or an explicitly authorized local adapter. Every action defines risk, preview, timeout, duplicate protection, and rollback behavior.

通过 Android Intent、通知访问、无障碍或明确授权的本地适配器实现可观察、最小权限的动作。每个动作都要定义风险、预览、超时、防重复与回滚行为。
