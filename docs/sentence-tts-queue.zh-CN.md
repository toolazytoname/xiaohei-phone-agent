# 句子 TTS 队列

`SentenceTtsQueue` 将有界文本流切分为句子，并让首句立即可用。后续句子只会在当前代际完成后推进。UI 与 Android TTS 回调线程之间的队列修改已同步，每项在所属代际内带单调递增序号。

替换文本流或取消会清空队列并递增代际。旧代际的完成事件会被忽略，所以已取消的文本无法恢复或在之后进入播报。该队列没有 Android TTS、网络、音频焦点、麦克风或自动恢复能力。

系统 TTS 适配器使用同一临界区处理完成、下一句提交、取消与销毁，停止不能插入“已出队但尚未交给引擎”的窗口。仅元数据日志展示代际、序号、待处理数、引擎 start 回调时延、取消原因和丢弃数，绝不记录播报正文。

真机验收必须关联首个引擎回调与真实 AudioFlinger 输出，观察至少一次有序跨句推进，再在尚有内容时停止并证明不再出现后续序号或 Active Track。真人可听感知与小于等于 300 ms 的人工打断目标仍属于独立 `VOICE-011`/真人门禁。
