# OnePlus 8T DSP Companion (local lifecycle probe)

This local-only, device-gated companion performs SoundTrigger preflight, model lifecycle, and bounded low-power recognition probes. The public source and APK contain no OEM model or library. Private inputs can be injected only into local Magisk build output outside the repository. Recognition uses `captureRequested=false`; the Companion does not retain PCM.

Validated locally on the OnePlus 8T / LineageOS 21 profile on 2026-08-09: after installation as a removable `system_ext` Magisk module, the Companion is a unique-UID `SYSTEM` package, has only its two allowlisted SoundTrigger permissions, leaves global `hidden_api_policy` at its default value, and lists Qualcomm module 0. With user-revocable `RECORD_AUDIO` granted and private matching H25 inputs supplied locally, load/unload passed, the HAL entered LPI, a screen-off acoustic “小布小布” produced second-stage confidence 99 and an Android callback, and a second trigger passed after automatic re-arm. The redacted callback also reached the ordinary Xiaohei app through its selected Android Assistant session. Final stop/unload/detach passed.

It is a separate package with a unique UID. `MANAGE_SOUND_TRIGGER` and `CAPTURE_AUDIO_HOTWORD` must come only from a partition-matched local `privapp-permissions` allowlist. Android 14 additionally checks user-revocable runtime `RECORD_AUDIO` before SoundTrigger attach; this does not authorize the Companion to retain command audio or create an always-on AudioRecord path. A signature-gated foreground service owns the armed lifecycle, while a signature-gated read-only provider exposes status without starting a background service. The ordinary Xiaohei app owns the controls and Android Assistant session used to display UI after a callback. Do not treat the public build as a generic Android APK.

Build locally with `./build.sh`. See `device-profiles/oneplus8t-lineageos21/dsp-companion-contract.md`.
