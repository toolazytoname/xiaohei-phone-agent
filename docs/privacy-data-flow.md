# Xiaohei data flow and retention

[简体中文](privacy-data-flow.zh-CN.md) · [Privacy notice](privacy.md) · [Threat model](threat-model.md)

Status: `SEC-002` implementation inventory as of 2026-08-11. This is a code-and-contract map, not a claim that a relay, Android OEM service, or third-party receiving endpoint has passed an independent privacy audit.

## Rules that apply to every category

- A model, Phone Agent, OpenCode, or root capability has no implicit right to read device data. It must pass its own typed policy, consent, and tool boundary; the current Conversation path has zero action authority.
- No raw audio, screen pixel, accessibility tree, prompt, notification body, or token is allowed in the app's redacted Agent JSONL trace, diagnostic export, public contract fixtures, Git, or public documentation.
- App-private state is not a public export. The only trace export is user-invoked, explicitly labelled as redacted, and handed to Android's chooser; choosing a destination is the user's separate disclosure decision.
- Uninstalling the app removes app-private files and preferences under normal Android package-data semantics. It does not erase content independently retained by Android, a selected TTS engine, a relay, or a user-selected share destination.

| Microphone audio | `AudioRecord` is opened only for a short recognition session (release maximum 8 s) or explicit foreground CPU KWS; local ASR/KWS consumes PCM in memory. ## Boundary checks and open evidence

The repository verifier checks that this bilingual table names all six required categories and the release-visible prohibitions. Unit and static checks cover the bounded session, privacy denials, trace exclusions, token-free backup, and no raw screenshot persistence. They do not inspect a remote endpoint, Android system service, another app, crash dump, OEM log, or user-selected export recipient.

Before a public release, repeat the data-flow test on an independent device with a real configured relay and capture only redacted evidence: permission/revoke transition, recorder count after stop, app-private file inventory, token-clear/restart, trace clear/export, and a denial for notification/location/private media. Do not put raw messages, audio, screenshots, endpoints, tokens, or device identifiers into Git.
