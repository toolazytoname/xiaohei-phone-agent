# 音频半双工协调器

`VOICE-004` 提供同步所有权规则：**输入**（识别/录音）与**输出**（TTS）不能同时持有。冲突获取被拒绝；终态释放将所有权回到 `NONE`。

进程级接线每次只签发一个绑定对象身份的 lease；重复获取会被拒绝，迟到或外来 lease 也不能释放当前所有者。它已接入小黑系统 TTS 适配器、本地 ASR 服务、系统 ASR 命令会话和可选 CPU 唤醒录音器。DSP 唤醒路径不获取 Android 麦克风 lease，因为当前 profile 不请求 capture，低功耗硬件路径由 DSP 自己持有。

确定性测试覆盖输入/输出冲突、重复获取、迟到释放和终态回到 `NONE`。真机验收还必须证明真实 TTS 音轨与 Active Recorder 不重叠，并在停止后双方归零；真人听感和口头打断仍属于独立门禁。
