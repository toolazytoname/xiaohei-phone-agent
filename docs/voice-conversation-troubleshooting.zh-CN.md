# 语音聊天故障排查

本页只适用于私有、含模型的 Conversation 预览；不诊断也不改动 DSP、CPU KWS、Phone Agent、OpenCode 或 Claude/Happy 配置。

| 现象 | 安全的第一步 | 不要做 |
|---|---|---|
| 点击说话提示 ASR 不可用 | 确认仍是私有含模型包且麦克风权限已授予；修复前使用文字聊天。 | 不要用无模型源码包覆盖私有模型包。 |
| partial 转写看起来错误 | 只完成本轮并看 final；需要时使用可编辑文字兜底。 | 不要反复重说同一句直到碰巧通过。 |
| 没有模型回复 | 查看可见 Conversation 配置和网络，只在条件变化后重试一次。 | 不要泄露 token/endpoint，也不要重复同一付费失败。 |
| 播报与其他应用冲突 | 点击停止播报；Android 失焦也应停止输出。 | 不要把 CPU KWS 当作解决方法。 |
| 蓝牙/耳机已变化 | 等路由稳定后手动开始新的说话轮次。 | 不要期待听取或播报跨路由变化继续。 |
| 需要完全停止 | 点击停止或结束聊天，并确认麦克风指示消失。 | 不要把强制停止作为常规控制方式。 |

可见停止后仍有录音时，只记录时间、公开状态标签和构建版本；撤销麦克风权限并报告问题，不提交转写、私有 App 截图、token 或原始日志。
