# 工具结果证据

`ToolOutcomeEvidenceGate` 规定适配器返回成功本身不足以证明工具结果。只有较新的最小观察满足预期前台包名时，工具结果才算验证成功。适配器失败、过期观察、包名不匹配或第二次验证都会 fail-closed。

该门只含包名元数据和快照序号，没有屏幕文字、树、图片、网络、工具或回滚执行能力。受限无障碍执行器现在会在每个已批准的点击、返回或滚动前创建该门，并在动作后以新的语义快照验证，之后才记录 `success`。适配器确认本身、过期观察或前台包名变化都会以“未验证”停止任务。TOOL-012 仍为 `VERIFY`：这条窄链路还需要在真实且已审核的设备/App/版本用例上取证，且不证明其他适配器目录已完成或可逆。
