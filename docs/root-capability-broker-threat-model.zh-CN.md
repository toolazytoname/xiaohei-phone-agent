# Root Capability Broker 威胁模型

状态：`ROOT-001` 的设计前置；本文不实现 root 执行器。

模型和 OpenCode 永远拿不到 `su -c`、交互 root shell、凭据路径或宽泛文件路径。未来 Broker 只能接收版本化动作 ID、精确 Schema、一次性 capability token、受限超时、审计记录和已定义的回滚。

## 候选允许列表

| 动作族 | 范围 | 默认 |
|---|---|---|
| 只读诊断 | 固定服务/包/端口/电池/音频查询 | 预览后允许 |
| 服务生命周期 | 仅小黑自有命名服务 | 确认并校验 PID/端口 |
| 设备 profile 回滚 | 仅签名、版本化 profile | 确认并重启校验 |

## 永久拒绝

- 通用 shell、任意命令字符串、任意路径、通配符、管道、重定向、下载、安装卸载、凭据/密钥目录、支付/OTP/密码界面、风控绕过和数据外传。
- 用户确认后目标变化、token 过期/重放/跨任务的请求。

## 恢复责任

每个允许的修改必须有前置快照、受限回滚和后置条件检查；无法定义回滚的动作直接拒绝，不能交给模型临场决定。
