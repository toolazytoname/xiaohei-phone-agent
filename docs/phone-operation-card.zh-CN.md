# 小黑手机离线操作卡

适用版本：内部 Alpha `0.2.0-alpha.2`。把本页下载到手机（或保存在本仓库的本地副本）后，断网也能查阅。

## 先记住这四件事

| 项目 | 是否默认开启 | 和其他项目的关系 |
|---|---:|---|
| 基础短命令 | 否；按首页按钮或系统助手进入 | 不要求 DSP、CPU 唤醒或 Phone Agent |
| CPU “小黑小黑”唤醒 | 否 | 会持续使用麦克风、有前台通知、功耗较高；**不改变 DSP** |
| OnePlus DSP 唤醒 | 仅已安装兼容增强包时可用 | 独立控制；**不改变 CPU 唤醒** |
| 语音播报 | Android 离线中文 TTS | 仅在需要回答时短暂工作；不是常驻服务，也不是唤醒路径 |
| Conversation 说话 | 点击前关闭 | 单个有界聊天轮次；不授予手机动作权限，也不改变 DSP/CPU KWS |
| Phone Agent 模型渠道 | 否 | 只保存复杂任务配置；**保存或切换不启动/停止任何服务** |

CPU 唤醒是通用实验兜底，不是低功耗 DSP。没有兼容 DSP profile 时，使用基础模式即可。

日常语音播报使用离线系统 TTS。在线 TTS 中转（包括兼容微软的服务）只能由你主动选择；它可能需要网络，既不是 DSP 唤醒所需组件，也不是离线短命令所需组件。

## 日常使用

1. 打开“小黑”。首页先看四类状态：语音会话、DSP、CPU 唤醒、Phone Agent。
2. 使用“按住说话”或系统助手入口，完成一条短命令，例如“打开相册”。
3. 状态变为完成、失败或取消后，麦克风应被释放；需要时再开始下一条命令。
4. 涉及发送、删除、安装、授权、拨号或安全设置时，核对目标和内容并亲自确认；聊天 App 的最终发送仍由你操作。

## 启停与状态

### CPU “小黑小黑”

- 开：主页点“启动‘小黑小黑’CPU 实验唤醒”，按系统提示授予麦克风。看到 `LISTENING` 和持续通知才表示正在监听。
- 用：说“小黑小黑”，等进入短命令会话，再说需求。结束后应回到 `LISTENING`。
- 停：主页点“停止 CPU 唤醒并释放麦克风”，或在持续通知点“停止并释放麦克风”。状态应为 `OFF`。
- 异常：若显示 `ERROR`，先停止一次，再检查麦克风权限；不要反复启动。仍失败时切回基础按键入口。

### OnePlus DSP（仅 OnePlus 8T 已验证 profile）

- 开：主页点“启动 DSP 低功耗唤醒”。只有状态显示 `ARMED` 才代表已待命。
- 停：主页点“停止并释放 DSP”。期望状态是 `DETACHED`。
- 异常：显示“未安装增强 profile”或“状态查询失败”时，不要重复点击；DSP 不可用不影响基础模式和 CPU 模式。
- 回滚：先停止并确认 `DETACHED`，再按设备专属安装/回滚包说明处理。不要把私有 OEM APK、模型或日志上传到公开仓库。

### 有界语音聊天（私有含模型预览）

1. 从主页进入**小黑对话**，确认 Conversation 已配置。它与 Phone Agent 和其他工具的模型渠道独立。
2. 点击**说话**，说一个普通、非敏感的问题，等待 final 转写；partial 不会发送。
3. 应用先做本地隐私/控制检查，之后最多发送一次 Conversation，并可用离线系统 TTS 播报。
4. 追问时点击**继续说**；播报后绝不会自动重新打开麦克风。
5. **停止播报**保留文字上下文；**停止**取消听取/请求/播报并暂停；**结束聊天**清空内存文字。
6. 蓝牙/耳机路由变化会刻意停止当前轮次。先检查路由，再手动开始新一轮。

### 全部停止（紧急）

- 主页点“全部停止：语音 + DSP + CPU 唤醒”。
- 若已开启常驻状态通知，也可在通知中点“全部停止”。
- Phone Agent 正在执行时，进入“可见 Phone Agent”，点“全局停止 Phone Agent”，或点其通知中的“停止 Agent”。

### Agent 找不到安全目标时

可见、低风险的 Phone Agent 任务提示找不到语义目标时，先由你自己查看页面。若已开启 Phone Agent 状态通知，任务的单次恢复窗口里会显示**一次本机视觉预览**：你点它后，系统只截取当前允许页面一次、立即停止任务；回到 Phone Agent 时会显示临时预览。预览只留在内存，不上传、不保存、不用于自动点击。看完后由你亲自重新输入精确的低风险目标。含有私人信息的页面不要请求预览；敏感页面会在截图前被拒绝。

停止后应没有待处理命令；若麦克风指示仍在，请在 Android 设置中强制停止小黑并撤销麦克风权限，再记录时间和页面状态用于诊断。

## 模型与渠道：只改配置，不开服务

进入主页“模型渠道 / Model channels”：

1. **ASR**：选择“小黑离线中文 ASR”或“Android 系统识别服务”。这只决定转写来源。
2. **Phone Agent**：需要复杂任务时才打开“启用 Phone Agent 渠道”；填写 HTTPS 中转站 URL、模型名和新 Token，点“保存独立配置”。Token 不会回显。
3. 关闭 Agent 开关并保存，即停用该渠道配置；不会停止 DSP、CPU 唤醒、llama.cpp、Happy、OpenCode Web 或 Claude Code。
4. 本机中转站只允许 `localhost` / `127.0.0.1` 的 HTTP；其他地址必须是 HTTPS。网络不可用时，优先使用离线 ASR 和确定性短命令。

每次修改后看页面提示“已保存；未启动任何服务”。遇到 URL 或 Token 错误时只改一次后重新保存，避免反复发起付费模型请求。

## 权限与隐私

- 麦克风：只用于主动短命令、明确点击的 Conversation 说话轮次或你手动启动的 CPU 唤醒；可随时在 Android 设置撤销。
- 通知访问：可选；只在主动查询时读取当前系统通知，不保存聊天正文。
- 无障碍：可选；只用于可见 Phone Agent 的用户发起任务。支付、银行、密码、验证码和 DRM 页面默认拒绝自动化。
- Phone Agent 状态通知：可选，但通知停止和一次本机视觉预览恢复需要它。Android 13+ 会明确请求这项权限；不希望有这些控制时可以拒绝。
- 要彻底停用：先执行“全部停止”，再到 Android 设置撤销上述权限；需要彻底移除时卸载小黑。OnePlus DSP 必须先确认 `DETACHED` 再卸载增强包。

## 一次有效的故障记录

同一个错误不要无意义重试。记录：时间、当前状态、你点的唯一入口、屏幕文字、是否联网/是否走 Clash、以及是否已全局停止。不要记录 Token、完整 URL、聊天正文、原始音频、设备序列号或私有 OEM 文件。
