# 音频中断策略

`AudioInterruptionPolicy` 将四类非内容中断来源——来电、闹钟、媒体和 Activity 生命周期——映射为一个 fail-closed 决定：停止输入、停止输出并释放音频所有权。它绝不自动恢复任一路径。

主页 Activity 的暂停路径现在会先经过策略，再停止活跃 ASR 会话。现有 ASR 音频焦点丢失已停止并释放输入；系统 TTS 有独立中断方法，但尚未有共享 Android 适配器把每种来源同时接到 ASR 和 TTS。

策略不会收集电话权限、通话元数据、闹钟文字、媒体元数据或音频内容。真实中断来源和音频资源仍需在设备上验证，所以 VOICE-005 保持 `VERIFY`。
