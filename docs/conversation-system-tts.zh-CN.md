# 对话系统 TTS 接线

[English](conversation-system-tts.md)

仅当独立的 Conversation TTS 通道被明确设置为 `system` 时，已接受的小黑回复和本地“重说上一条”才会交给 `SystemTtsAdapter` 播报。文字对话仍是半双工，模型也没有手机动作权限。

对话页提供独立的“停止播报（保留聊天）”按钮：它会中断当前系统 TTS 流，但不清空已显示的聊天。聊天停止、清空、离开页面、锁屏/后台清理和 Activity 销毁也会中断并取消待播句子；所有这些路径都不会自动恢复音频。

`off` 和 `relay` 不会创建系统适配器。Android 没有可用 TTS 引擎或初始化失败时，只显示本地状态，不影响模型请求，也不会触发手机动作。

## 证据边界

这是 Android 运行时接线，不等于某台设备已有 TTS 引擎，更不等于可听打断低于 300ms。`VOICE-011` 在设备实测留下该证据前保持 `VERIFY`。语音抢话会在回声循环资格验证前保持不在范围内。
