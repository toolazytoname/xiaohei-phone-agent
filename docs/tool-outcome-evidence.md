# Tool outcome evidence

`ToolOutcomeEvidenceGate` makes a successful adapter response insufficient by itself. A tool result is verified only when a newer minimal observation has the expected foreground package. Adapter failure, a stale observation, a mismatched package, or a second verification attempt fails closed.

The gate contains only package metadata and snapshot sequence; it has no screen text, tree, image, network, tool, or rollback execution capability. The bounded Accessibility executor now constructs it immediately before each approved click, back, or scroll and verifies a new post-action semantic snapshot before recording `success`. An adapter acknowledgement alone, a stale observation, or a changed foreground package stops the task as unverified. TOOL-012 remains `VERIFY` until this is exercised against real reviewed device/app/version cases; this narrow wiring does not certify an unrelated or reversible-adapter catalog.
