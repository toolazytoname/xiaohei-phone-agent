# 路线图

[English](roadmap.md) · [厂商级详细交付清单](product-delivery-plan.zh-CN.md)

小黑分成“通用产品”和“高级唤醒后端”两条轨道。可下载产品不等待厂商 DSP 适配完成。

## 通用产品轨道

| 里程碑 | 结果 | 退出门禁 |
|---|---|---|
| P0 — 产品骨架 | 独立双语产品仓库与公开契约 | 仓库边界与 CI 验证通过 |
| P1 — 通用 Android Alpha | 按钮/快捷设置、短命令 ASR 与“打开相册” | 在声明的未 root Android 上工作，不依赖 DSP |
| P2 — 系统助手入口 | 设备支持时可由用户选择为助手/会话入口 | 运行时能力探测，并明确展示 OEM 限制 |
| P3 — 通知助手 | 读取通知层未读状态 | 用户主动授权、本地汇总、不遍历聊天 |
| P4 — 确认后回复 | 草拟并确认一条消息回复 | 展示收件人与内容、明确确认、无后台批量动作 |
| P5 — 公开 Alpha | 可复现安装、UI、文档与 Release | 新设备测试、CI、正式签名 APK、checksum 与双语说明 |

## 高级唤醒后端轨道

| 里程碑 | 结果 | 退出门禁 |
|---|---|---|
| W0 — OnePlus DSP 证据 | 原厂中文词进入 ADSP/LPI 并得到 Android callback | OnePlus 8T 已完成，干净回滚通过 |
| W1 — 后端接口 | 手动、系统助手、CPU KWS 与 DSP 实现统一能力契约 | 不支持的后端不能启用，也不能阻塞基础模式 |
| W2 — OnePlus DSP Broker | 独立 UID 的最小 Android 14 组件 | 三次冷启动、三次启停、卸载与异常恢复均实测 |
| W3 — 功耗资格 | 物理拔线下比较 DSP OFF/ARMED | 三轮 60 分钟 A/B，无普通 AudioRecord/持续 AP wakelock，8–24 小时回归 |
| W4 — 自定义唤醒词 | 原生“小黑”模型或明确标注的 CPU fallback | 重新通过 W3 的功耗/准确率/回滚门禁 |
| W5 — 更多设备 | 第二个独立验证的硬件/ROM profile | OnePlus 专属代码不泄漏进通用核心 |

每个里程碑只产出一份结构化验收记录。相同失败指纹没有新证据时，不重复声学测试、截图或模型调用。
