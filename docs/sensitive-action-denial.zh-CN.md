# 敏感动作永久拒绝

[English](sensitive-action-denial.md) · [授权层](authorization-tiers.zh-CN.md) · [状态](../STATUS.md)

`POLICY-004` 是在语义 UI 动作之前执行的本地 fail-closed 语料库。任何匹配支付或转账、认证秘密（包括 OTP/CVV/密码），或者绕过验证、风控和安全保护的包名、可见文本或请求标签都会永久拒绝；它覆盖中英文变体。

这是拒绝边界，不是意图分类器：未匹配并不授予权限，仍必须经过工具目录、层级策略、确认和网关。该策略没有模型、UI、网络、root 或执行路径。新敏感变体必须扩充回归语料，不能削弱默认拒绝。
