# 小黑真人中文语音评测协议 v1

[English](voice-evaluation-protocol.md) · [执行账本](execution-backlog.zh-CN.md) · [状态页](../STATUS.md)

状态：`VOICE-006` 的公开协议。原始音频、逐字转写、说话人身份和私人命令不得提交到 Git。

## 目的

用可重复、可脱敏的方式衡量“小黑小黑”后的短命令与后续开放问句。结果用于模型和阈值选择，不用于训练，也不能替代物理功耗验收。

## 采样设计

至少 30 条、最多 50 条真人中文 utterance，覆盖：

| 维度 | 最低覆盖 |
|---|---|
| 说话人 | 至少 3 名成人；仅记录匿名编号 `S1`、`S2`、`S3` |
| 距离 | 30 cm、1 m、2 m |
| 环境 | 安静室内、普通室内噪声、轻度户外噪声 |
| 命令 | 相册、设置、蓝牙、相机、浏览器、停止、未读查询、歧义/拒绝 |
| 开放问句 | 至少 10 条不含动作请求的日常问句 |
| 负例 | 至少 10 条近音词、普通谈话或非唤醒词 |

不要采集电话号码、真实联系人、地址、验证码、密码、聊天正文、私有照片标题或工作机密。

## 运行规则

1. 使用候选 APK、固定 build hash、固定唤醒/ASR profile；记录版本但不记录 Token 或 endpoint。
2. 每条只播放或说一次；同一失败指纹不得反复重说，除非环境、距离、profile 或 build 已改变。
3. 每次开始前确认 CPU KWS/DSP 状态、音量、网络状态和锁屏状态；功耗采样窗口内禁止进行此测试。
4. 只保留脱敏汇总表；原始音频若临时保存，测试完成后由说话人确认删除。
5. 高风险动作一律使用安全替代语料（例如“打开相册”），不测试自动发送、支付、验证码或 root 修改。

## 脱敏结果表

把下表复制到本地私有表格或 issue 附件；公开报告仅提供聚合数值。

| Case | Speaker | Distance | Environment | Category | Expected intent | ASR exact? | Routed safely? | Latency ms | Result | Notes |
|---|---|---|---|---|---|---:|---:|---:|---|---|
| C01 | S1 | 30cm | quiet | command | OPEN_GALLERY | yes/no | yes/no | number | pass/fail | no transcript |

`Routed safely` 的含义是：正确动作、正确追问或安全拒绝三者之一；听错成另一个动作一律算失败。

## 通过门槛与报告

- 命令语义安全率、开放问句可理解率、假唤醒/误动作数、P50/P95 延迟分别报告；不要只报告总准确率。
- 任何错误执行高风险动作、录音服务残留、崩溃或无法停止均为该 build 失败。
- 未达到预先声明的门槛可标为 `VERIFY`，不能通过调阈值后只重新报告成功案例。
- 公开报告仅包含设备类别、版本、分桶样本数、汇总指标、已知限制和删除确认；原始数据保持私有或删除。
