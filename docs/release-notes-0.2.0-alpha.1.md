This is an internal, locally signed acceptance build, not a public Release.

Highlights: portable push-to-talk and Quick Settings entry; optional OnePlus 8T DSP enhancement; bounded offline Chinese ASR; deterministic low-risk commands; private current-notification summaries; visible confirmation-only reply drafts; independent ASR and Phone Agent channels; policy-gated semantic Phone Agent foundation; global stops; redacted diagnostics; transactional uninstall.

Known limitations: wake phrase remains the OEM “Xiaobu Xiaobu”; no independent non-OnePlus acceptance device; no real isolated messaging-account test; Phone Agent app matrix and screenshot fallback incomplete; no approved model redistribution; idle/power and formal signing gates incomplete.
