# Permission center

The main page provides a read-only bilingual permission center for microphone, camera, notifications, notification access, Accessibility, and the unavailable root broker. Each entry states purpose, the current bounded status, recent-use availability, and the Android settings path where the user can revoke it.

The center never asks for, grants, revokes, or expands a permission. **Open system permission settings** is only a user-initiated jump to Android's app-details page. Special accesses remain under Android system settings; root remains unsupported and unwired.
