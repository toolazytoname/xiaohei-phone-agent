# Root system-change preview

[简体中文](root-system-change-preview.zh-CN.md) · [profile transaction](root-profile-transaction.md)

`ROOT-007` accepts only a fixed profile target with distinct SHA-256 before/after digests, fresh confirmation, and no expiry. It returns the fixed summary `profile-digest-change`; target values and digests do not enter the result. It has no apply, root, shell, file, or device path.
