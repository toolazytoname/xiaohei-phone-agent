# 隐私说明 — 小黑助手

小黑只在可见、有时限的短命令会话中使用麦克风，并在结果、错误、中断或停止时立即释放。离线构建在设备本地处理语音。独立配置的 Phone Agent 中转默认关闭；保存或切换模型配置不会启动它。

通知访问完全可选。授权后，小黑只在用户主动查询时读取系统当前通知，不持久化通知内容，也不会在锁屏会话中暴露内容。回复草稿只显示在界面上，永不自动发送；当前版本只有在用户核对 App、目标和完整内容后才打开目标 App，最终发送仍由用户亲自操作。

可选 OnePlus DSP profile 使用设备本地关键词模型。进入主 APK 的只有关键词 ID、置信度和 capture 标志，不含唤醒音频。用户可从产品页或常驻状态通知同时停止语音与 DSP，可在 Android 设置撤销通知访问、清除 Phone Agent Token，并按事务式回滚文档完整卸载。
