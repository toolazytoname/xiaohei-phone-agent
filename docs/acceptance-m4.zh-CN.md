# M4 通知与确认式草稿验收记录

日期：2026-08-09  
设备：OnePlus 8T / Android 14；独立 Android 14 AOSP ARM64 设备

## 真机证据

- 撤销通知访问时，“微信有没有未读消息”明确返回“尚未授权”，没有读取通知。测试中主动授权后，只统计系统当前、非常驻通知并列出来源 App。
- 息屏状态执行相同查询时，产品返回锁屏隐私拒绝。门禁把拉起前的息屏/Keyguard 状态绑定到本次会话，因此 `showWhenLocked` 不会抹掉隐私判断。
- 通知标题、正文、联系人和历史都不写入 SharedPreferences 或文件；汇总仅来自 `getActiveNotifications()`，通知消失即失效。
- 因手机未安装真实微信、也没有隔离测试账号，本轮用明确标注“NOT WeChat”的本地测试夹具在微信包名下发出一条通知。“回复微信说我晚点到”完整展示 App、目标“测试联系人”和草稿全文；取消按钮没有打开应用。
- 可见确认只打开测试 App；小黑没有填输入框、调用 RemoteInput、点击发送或使用 Accessibility。确认前删除通知后，新鲜性复查会取消操作。
- 验收结束已卸载夹具，手机再次不存在 `com.tencent.mm`。
- 产品现把通知监听断开也当作隐私事件：它只发布同包的访问布尔值，不携带任何通知元数据，并清除可见待确认草稿。部分 Android 构建不会可靠回调监听断开，因此只要草稿存在，前台草稿页还会每秒仅读取“是否仍获访问”的布尔值，在撤销后一秒内清除。
- 独立 AOSP 设备完成运行中撤权全链路：Messaging 草稿和确认按钮可见时撤销通知监听，限定前台检查后草稿与确认节点均变为 0，界面明确提示授权撤销、草稿已清除。AOSP 真正撤权后仍保留过期 Secure Settings 组件字符串；API 27+ 现改用 Android 权威的 `NotificationManager.isNotificationListenerAccessGranted()`，状态和隐私判断不再相信该旧字符串。
- 测试夹具覆盖 PUBLIC、PRIVATE、SECRET 三种通知可见性：解锁时 PUBLIC/PRIVATE 显示合成测试目标，SECRET 只显示“隐私会话”。夹具随后卸载，且不冒充隔离账号证据。
- 独立非主消息证据来自 AOSP 模拟器真实接收的模拟 SMS 和系统 `com.android.messaging`，发送/接收身份均为合成测试身份。产品现只支持精确列出的微信与 AOSP Messaging 适配器。“回复消息说收到”展示 Messaging、合成会话目标和完整草稿；精确通知 key 仍存在时点击确认，只打开系统会话列表。SMS 已发送 Provider 行数前后都是 0，页面没有预填输入框或自动发送；小黑 SharedPreferences/文件中也没有匹配的合成号码、标题或正文。息屏命令没有生成草稿。

## 安全边界

通知访问完全可选且由用户授权。锁屏会话不暴露通知内容。回复草稿只在内存中存在、绑定当前仍可见通知，并要求一次新的可见确认。当前产品永不自动发送消息。

## M4 出口结论

OnePlus 与独立 AOSP 证据覆盖了可选授权、未读能力限制、锁屏/息屏隐私、PUBLIC/PRIVATE/SECRET 变体、通知消失与精确 key 新鲜性、草稿可见时撤权、隔离非主消息身份、目标/内容确认，以及发送箱始终为 0 的人工发送行为。这里不声称无人值守微信自动化，真实微信主账号仍不进入测试范围。验收后已撤销通知访问并清除夹具/测试消息。M4 已完成。
