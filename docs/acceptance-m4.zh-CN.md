# M4 通知与确认式草稿验收记录

日期：2026-08-09  
设备：OnePlus 8T / Android 14

## 真机证据

- 撤销通知访问时，“微信有没有未读消息”明确返回“尚未授权”，没有读取通知。测试中主动授权后，只统计系统当前、非常驻通知并列出来源 App。
- 息屏状态执行相同查询时，产品返回锁屏隐私拒绝。门禁把拉起前的息屏/Keyguard 状态绑定到本次会话，因此 `showWhenLocked` 不会抹掉隐私判断。
- 通知标题、正文、联系人和历史都不写入 SharedPreferences 或文件；汇总仅来自 `getActiveNotifications()`，通知消失即失效。
- 因手机未安装真实微信、也没有隔离测试账号，本轮用明确标注“NOT WeChat”的本地测试夹具在微信包名下发出一条通知。“回复微信说我晚点到”完整展示 App、目标“测试联系人”和草稿全文；取消按钮没有打开应用。
- 可见确认只打开测试 App；小黑没有填输入框、调用 RemoteInput、点击发送或使用 Accessibility。确认前删除通知后，新鲜性复查会取消操作。
- 验收结束已卸载夹具，手机再次不存在 `com.tencent.mm`。
- 产品现把通知监听断开也当作隐私事件：它只发布同包的访问布尔值，不携带任何通知元数据，并清除可见待确认草稿。部分 Android 构建不会可靠回调监听断开，因此只要草稿存在，前台草稿页还会每秒仅读取“是否仍获访问”的布尔值，在撤销后一秒内清除。该实现已通过编译/静态校验；仍需下方所列的全链路撤销复验。

## 安全边界

通知访问完全可选且由用户授权。锁屏会话不暴露通知内容。回复草稿只在内存中存在、绑定当前仍可见通知，并要求一次新的可见确认。当前产品永不自动发送消息。

## 尚未满足的 M4 出口门禁

夹具已证明权限、隐私、确认、取消和通知消失处理，但不能冒充真实隔离微信账号证据。最终仍需用非主账号的受支持消息 App 验收隐私通知变体、运行中撤权以及文档所述的人工发送行为。
